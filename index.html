Connect GitHub — Free Cloud Sync

Your products and images will be saved in a GitHub repository. 100% free, no credit card, no billing ever.

Step 1 — Create a GitHub account
Go to github.com/signup (free)

Step 2 — Create a new repository
Click + → New repository → name it perfume-inventory → set to Public → Create repository

Step 3 — Create an Access Token
Profile picture → Settings → scroll down → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)
Check repo checkbox → scroll down → Generate token → copy the token immediately

Step 4 — Enable GitHub Pages
In your repo → Settings → Pages → Source: Deploy from a branch → Branch: main → Save
Your site will be at: https://YOUR-USERNAME.github.io/perfume-inventory
